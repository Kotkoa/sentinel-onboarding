# WORKLOG — SENTINEL Onboarding

> Живой журнал процесса. Ведётся **по ходу работы**, а не постфактум.
> Автоматические строки (`- [timestamp] prompt: ...`) дописывает `UserPromptSubmit` hook
> на каждый ввод. Ручные записи решений добавляются скиллом `/worklog`.
> В конце проекта консолидируется в `APPROACH.md`.

Проект: прототип SPA для risk-классификации онбординга клиентов (Halcyon Capital Partners / SENTINEL).
Стек: Vite + React + TypeScript (strict) + Tailwind v4 + Supabase (за repository-абстракцией).
